# Living Cultivation World — Outcomes

- [x] **Persistent flow of time and evolving world** — Game time advances while the game runs and resumes from saved elapsed time; the world periodically produces new, contextual events and characters; recent event templates do not repeat immediately; world records survive reloads.
- [x] **Cultivation paths and divine ability** — The player can choose a path with distinct bonuses and use a path-flavored divine ability subject to a cooldown.
- [x] **Open-world map and exploration** — The player can travel among named regions; regions vary in danger/reward, affect event generation, and record which places have been visited.
- [x] **Sects and disciples** — The player can join a sect, contribute resources, generate/recruit named disciples, and preserve disciple records and capacity constraints.
- [x] **Heart demons, forbidden routes, and heavenly punishments** — Breakthrough failure and forbidden cultivation can produce lasting risk; the player can confront a heart demon and survive/resolve heavenly tribulation with visible state changes.
- [x] **Balance, compatibility, and game reliability** — Existing browser saves load with safe defaults; resources and odds remain bounded; existing cultivation, exploration, crafting, combat, and reset flows remain operational; strict typecheck and production build complete.
